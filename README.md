# Telegram Shop Bot Template

## Описание

Этот репозиторий содержит шаблон телеграм-бота для интернет-магазина. Проект построен на `aiogram` и `SQLAlchemy` и демонстрирует ключевые функции e-commerce в Telegram: регистрацию клиента, каталог товаров, карточки продуктов, корзину и базовую админ-панель.

Это стартовая основа для создания собственного магазина в Telegram. Реализация позволяет быстро подключить базы данных, настроить товарные категории и начать принимать заказы через группу или канал.

## Что умеет бот

- Приветственная логика и регистрация пользователя через `/start`.
- Сбор имени и телефона клиента.
- Просмотр списка категорий магазина.
- Отображение карточек товаров с изображением, описанием и ценой.
- Переход к экрану покупки товара и запрос адреса доставки.
- Прием геолокации или ввод адреса вручную.
- Отправка уведомления о новом заказе в Telegram-группу, указанную в `GROUP_ID`.
- Админ-панель для управления магазином:
  - добавление новых категорий;
  - добавление товарных карточек;
  - удаление категорий и товаров;
  - добавление и удаление людей, которые имеют доступ к панеле.

## Мотивация

Этот проект удобен для разработчиков, которые хотят:

- быстро запустить MVP магазина в Telegram;
- изучить работу с `aiogram` и `SQLAlchemy`; 
- получить готовую структуру для клиентской и админской логики; 
- доделать и адаптировать бот под собственный ассортимент, оплату и доставку.

## Структура проекта

- `run.py` — точка входа, инициализация бота и роутеров.
- `app/client.py` — обработка пользовательских команд, регистрация, каталог и заказ.
- `app/admin.py` — административный workflow для управления товарами и категориями.
- `app/keyborads.py` — клавиатуры и inline-кнопки для пользовательского интерфейса.
- `app/validtion.py` — простая проверка номера телефона.
- `app/database/models.py` — модели базы данных для пользователей, категорий, товаров и корзины.
- `app/database/requests.py` — методы доступа к данным пользователя, категорий и товаров.
- `app/database/requests_cart.py` — базовая логика корзины.
- `requirements.txt` — список зависимостей проекта.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-аккаунт>/<репозиторий>.git
   cd test_shop_bot
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` в корне проекта с переменными:
   ```env
   TG_TOKEN=ваш_токен_бота
   DB_URL=sqlite+aiosqlite:///./shop.db
   GROUP_ID=ID_вашей_telegram_группы
   # REDIS_HOST=localhost
   # REDIS_PORT=6379
   # REDIS_DB=0
   ```

5. Запустите бота:
   ```bash
   python run.py
   ```

## Переменные окружения

- `TG_TOKEN` — токен Telegram-бота.
- `DB_URL` — строка подключения к базе данных.
- `GROUP_ID` — ID чата или группы, куда отправляются уведомления о заказах.
- `REDIS_HOST`, `REDIS_PORT`, `REDIS_DB` — опциональные параметры для Redis, если вы подключаете FSM-хранилище.

## Как расширять шаблон

- Добавьте хранение заказов в базе данных.
- Реализуйте полноценную корзину с подсчетом стоимости и редактированием позиции.
- Подключите оплату через провайдеры или внешние системы.
- Защитите админ-панель списком администраторов или паролем.
- Расширьте модель `Card` полями `размер`, `цвет`, `наличие` и т.д.
